# Mutual Fund Capstone Project

A comprehensive data analysis and visualization project for mutual fund market insights. This project fetches live NAV (Net Asset Value) data, ingests multiple data sources, and provides tools for analysis and dashboarding.

## 📁 Project Structure

```
mutual-fund-capstone/
├── README.md                    # This file
├── requirements.txt             # Python dependencies
├── data_ingestion.py           # Data ingestion and exploration script
├── fetch_nav.py                # Fetch historical NAV data for multiple schemes
├── live_nav_fetch.py           # Fetch live NAV data for HDFC 100 scheme
├── data/                       # Data directory (NOT included in GitHub)
│   ├── raw/                    # Raw data files from various sources
│   └── processed/              # Processed and cleaned data
├── dashboard/                  # Dashboard application files
├── notebooks/                  # Jupyter notebooks for EDA and analysis
│   ├── eda_fund_master.ipynb  # Exploratory Data Analysis notebook
│   └── data_quality_amfi.ipynb # Data validation and quality checks
├── project/                    # Project-specific utilities and configurations
├── reports/                    # Generated reports and visualizations
├── sql/                        # SQL queries and database scripts
└── env/                        # Python virtual environment (local only)
```

## ⚠️ Important: Data Folder Structure

**The `data/` folder is NOT included in this GitHub repository.** You need to set it up locally to run the project.

### How to Set Up the Data Folder

1. Create the following directory structure in your project root:
```
data/
├── raw/
└── processed/
```

2. **Place your CSV files in the `data/raw/` directory:**

### Raw Data Files Description

The following CSV files should be placed in `data/raw/`:

#### Fund Master Data
- **`01_fund_master.csv`**
  - Contains master information about all mutual fund schemes
  - Includes scheme names, fund houses, categories, and fund type classifications

#### NAV and Historical Data
- **`02_nav_history.csv`**
  - Historical Net Asset Value (NAV) data for various schemes
  - Contains date, NAV values, and scheme identifiers

- **`hdfc_100.csv`** (Generated by `live_nav_fetch.py`)
  - HDFC Bank NIFTY 100 Index Fund NAV history
  - Columns: `date`, `nav`

- **`sbi_bluechip.csv`** (Generated by `fetch_nav.py`)
  - SBI Blue Chip Fund NAV history
  - Columns: `date`, `nav`

- **`icici_bluechip.csv`** (Generated by `fetch_nav.py`)
  - ICICI Blue Chip Fund NAV history
  - Columns: `date`, `nav`

- **`nippon_large_cap.csv`** (Generated by `fetch_nav.py`)
  - Nippon Large Cap Fund NAV history
  - Columns: `date`, `nav`

- **`axis_bluechip.csv`** (Generated by `fetch_nav.py`)
  - Axis Blue Chip Fund NAV history
  - Columns: `date`, `nav`

- **`kotak_bluechip.csv`** (Generated by `fetch_nav.py`)
  - Kotak Blue Chip Fund NAV history
  - Columns: `date`, `nav`

#### AUM and Market Inflow Data
- **`03_aum_by_fund_house.csv`**
  - Assets Under Management (AUM) data aggregated by fund house
  - Shows fund house size and market presence

- **`04_monthly_sip_inflows.csv`**
  - Monthly Systematic Investment Plan (SIP) inflows data
  - Tracks new SIP contributions over time

- **`05_category_inflows.csv`**
  - Inflows aggregated by fund category (equity, debt, hybrid, etc.)
  - Shows category-wise market trends

#### Holdings and Composition
- **`06_industry_folio_count.csv`**
  - Industry-wise portfolio composition
  - Count of holdings per industry sector

- **`09_portfolio_holdings.csv`**
  - Detailed portfolio holdings for various schemes
  - Contains security names, quantities, and percentages

#### Performance and Benchmarking
- **`07_scheme_performance.csv`**
  - Performance metrics for various schemes
  - Includes returns, volatility, and Sharpe ratios

- **`10_benchmark_indices.csv`**
  - Benchmark index data and returns
  - Used for comparing scheme performance

#### Transaction Data
- **`08_investor_transactions.csv`**
  - Historical investor transaction data
  - Contains transaction types, amounts, and dates

## 📋 Python Scripts

### `data_ingestion.py`
**Purpose:** Load and explore all CSV files from the raw data folder
- Reads all CSV files from `data/raw/`
- Displays first 5 rows of each dataset
- Shows data types and dataset dimensions
- **Usage:**
  ```bash
  python data_ingestion.py
  ```

### `fetch_nav.py`
**Purpose:** Fetch historical NAV data for 5 major blue chip schemes from MF API
- Fetches data for:
  - SBI Blue Chip (Scheme Code: 119551)
  - ICICI Blue Chip (Scheme Code: 120503)
  - Nippon Large Cap (Scheme Code: 118632)
  - Axis Blue Chip (Scheme Code: 119092)
  - Kotak Blue Chip (Scheme Code: 120841)
- Saves data as CSV files in `data/raw/`
- **Usage:**
  ```bash
  python fetch_nav.py
  ```

### `live_nav_fetch.py`
**Purpose:** Fetch and save live NAV data for HDFC Bank NIFTY 100 Index Fund
- Fetches current NAV data from the MF API
- Scheme Code: 125497 (HDFC Bank NIFTY 100 Index Fund)
- Saves data as `hdfc_100.csv` in `data/raw/`
- Sorts data by NAV in descending order
- **Usage:**
  ```bash
  python live_nav_fetch.py
  ```

## 📓 Jupyter Notebooks

### `notebooks/eda_fund_master.ipynb`
Exploratory Data Analysis (EDA) notebook for the fund master dataset. Contains:
- Data exploration and visualization
- Statistical summaries
- Fund category and fund house analysis

### `notebooks/data_quality_amfi.ipynb`
Data validation and quality check notebook for AMFI (Association of Mutual Funds in India) datasets. Contains:
- Data integrity validation
- Missing value analysis
- Data quality metrics and anomaly detection
- Data consistency checks across multiple sources

## 🔧 Installation & Setup

### Prerequisites
- Python 3.8 or higher
- pip (Python package manager)

### Steps

1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   cd mutual-fund-capstone
   ```

2. **Create and activate a virtual environment:**
   ```bash
   # Windows
   python -m venv env
   env\Scripts\activate
   
   # macOS/Linux
   python3 -m venv env
   source env/bin/activate
   ```

3. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Set up the data folder:**
   - Create `data/raw/` and `data/processed/` directories
   - Place your CSV files in `data/raw/` (see Data Folder Structure section above)

## 🔗 API Reference

### MF API (mfapi.in)
- **Endpoint:** `https://api.mfapi.in/mf/{scheme_code}`
- **Returns:** JSON with NAV data
- **Format:** Daily NAV with date and value
- **Scheme Codes Used:**
  - HDFC Bank NIFTY 100: 125497
  - SBI Blue Chip: 119551
  - ICICI Blue Chip: 120503
  - Nippon Large Cap: 118632
  - Axis Blue Chip: 119092
  - Kotak Blue Chip: 120841
